# Linux

**الهدف:** التعامل مع أنظمة لينكس من سطر الأوامر، وهو أساس العمل مع السيرفرات على السحابة
**التكلفة:** المصادر التالية مجانية

## مصادر التعلم
- [Linux Journey](https://linuxjourney.com/) - دروس مبسطة تبدأ من الصفر
- [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) - ألعاب تطبيقية تتعلم فيها الأوامر بالممارسة
- [Introduction to Linux (LFS101)](https://training.linuxfoundation.org/training/introduction-to-linux/) - كورس مجاني من Linux Foundation

## نصيحة للتطبيق
أنشئ سيرفر Linux صغير على AWS (خدمة EC2)، واتصل فيه وجرب الأوامر عليه. وتأكد من شروط الطبقة المجانية، واحذف السيرفر بعد ما تخلص.
