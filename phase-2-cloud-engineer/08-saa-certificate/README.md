# AWS Certified Solutions Architect - Associate

**الهدف:** الشهادة المهنية التي تتوّج مرحلة هندسة السحابة
**التكلفة:** الاختبار مدفوع، تأكد من السعر الحالي من الموقع الرسمي

## الصفحة الرسمية
- [AWS Certified Solutions Architect - Associate](https://aws.amazon.com/certification/certified-solutions-architect-associate/)

## مصادر المذاكرة
- AWS Skill Builder: مواد التحضير الرسمية والأسئلة التجريبية
- كورس SAA-C03 على قناة freeCodeCamp (يوتيوب): كورس مجاني كامل
- اختبارات تجريبية من Tutorials Dojo (مدفوعة، تكلفتها منخفضة)

## نصائح للمذاكرة
- لا تحجز الاختبار إلا بعد أن تتجاوز الاختبارات التجريبية بنتيجة ثابتة فوق 80%
- لا تستخدم "الدمبات" (brain dumps)، فهي لا تعلّمك شيئاً وتخالف قواعد AWS
- طبّق عملياً على حساب AWS بدل الاكتفاء بالمشاهدة

## ملاحظات
- النسخة الحالية SAA-C03، وهناك توقعات بصدور نسخة جديدة، تأكد من الموقع الرسمي قبل الحجز
- لا يوجد دعم تمويل لهذا الاختبار حالياً، يحتاج نقاش

## مطلوب
- روابط مباشرة لمصادر المذاكرة
- خطة مذاكرة مقترحة (أسابيع وأهداف)
