## Overview

## 1. Secondary Transaction Deduplication in Sale Info
After normalizing the database into three separate tables, deep inspection of the sales records revealed that several identical financial transactions were recorded multiple times. These duplicates shared the identical sale price, sale date, and legal reference number, which artificially distorted total revenue figures.

## Identifying Duplicate Transactions
Using the ROW_NUMBER window function partitioned by SalePrice, SaleDate, and LegalReference, duplicate rows were isolated:

```sql
SELECT
    ROW_NUMBER() OVER (PARTITION BY "SalePrice",
                                    "SaleDate",
                                    "LegalReference"
                        ORDER BY "UniqueID") AS row_num,
    *
FROM saleinfo;
```

[images/saleinfo_duplicate_transactions.png]

A specific transaction with legal reference 201604050032679 and sale price 40000 appeared over 54 times in the records.

[images/repetitive_transactions_view.png]

## Purging Redundant Transactions
To resolve this issue, an isolated subquery targeted and deleted all duplicate transaction entries where row_num exceeded 1:

```sql
DELETE
FROM saleinfo
WHERE "UniqueID" IN
(
    SELECT "UniqueID"
    FROM
    (
        SELECT "UniqueID",
               ROW_NUMBER() OVER (PARTITION BY "SalePrice",
                                               "SaleDate",
                                               "LegalReference"
                                   ORDER BY ("UniqueID")) AS row_num
        FROM saleinfo
    )
    WHERE row_num > 1
);
```

Validation Result: Approximately 4000 duplicate rows were removed. Running the duplicate validation query returned zero rows, securing clean and accurate transaction metrics.

# 2. Advanced Feature Engineering
# 2.1 Price Value Categorization
To segment sales transactions into meaningful market tiers, the PERCENTILE_CONT function calculated statistical quartiles across all recorded sale prices:

- 25th Percentile (Low Threshold): 135000
- 50th Percentile (Median Price): 201000
- 75th Percentile (High Threshold): 314900

[images/price_percentiles_calculation.png]

A new column named SalePrice_Value was added to saleinfo and populated through a CASE statement:

```sql
ALTER TABLE saleinfo
ADD SalePrice_Value VARCHAR(255);

UPDATE saleinfo
SET SalePrice_Value = CASE WHEN "SalePrice" <= 135000 THEN 'LOW'
                           WHEN "SalePrice" >= 314900 THEN 'HIGH'
                           ELSE 'AVG'
                      END;
```

## 2.2 Net Income and Margin Calculation
To evaluate the actual financial margin generated by each property transaction, a new numeric column named Income was introduced. It calculates the difference between the final sale price and the total assessed property value (LandValue plus BuildingValue):

```sql
ALTER TABLE saleinfo
ADD Income NUMERIC;

UPDATE saleinfo
SET Income = ("SalePrice" - "TotalValue");
```

[images/net_income_calculation.png]

## 2.3 Transaction Profitability Classification
Using the calculated Income values, transactions were classified into distinct operational outcomes:

- Profitable: Properties selling above their total assessed value (Income greater than 0).
- Unprofitable: Properties selling below their total assessed value (Income less than 0).

```sql
ALTER TABLE saleinfo
ADD status VARCHAR(255);

UPDATE saleinfo
SET status = CASE WHEN "income" > 0 THEN 'Profitable'
                  WHEN "income" < 0 THEN 'Unprofitable'
             END;
```

[images/profitability_status_classification.png]

## 2.4 Property Age and Architectural Era Categorization
Within the propertyinfo table, construction years were categorized into six historical and architectural eras to observe how building age influences value and buyer demand:

- Before 1900: 90 Very Old
- 1900 to 1949: 49 Old
- 1950 to 1969: 69 Mid Century
- 1970 to 1999: 99 Relatively Modern
- 2000 to 2009: 09 Modern
- After 2009: Cur Very Modern

```sql
ALTER TABLE propertyinfo
ADD propertyage VARCHAR(255);

UPDATE propertyinfo
SET propertyage = CASE WHEN "YearBuilt" < 1900 THEN '90 Very Old'
                       WHEN "YearBuilt" BETWEEN 1900 AND 1949 THEN '49 Old'
                       WHEN "YearBuilt" BETWEEN 1950 AND 1969 THEN '69 Mid Century'
                       WHEN "YearBuilt" BETWEEN 1970 AND 1999 THEN '99 Relatively Modern'
                       WHEN "YearBuilt" BETWEEN 2000 AND 2009 THEN '09 Modern'
                       WHEN "YearBuilt" > 2009 THEN 'Cur Very Modern'
                  END;
```

## 3. SQL Views for Business Intelligence
## 3.1 Daily Net Revenue View
To track ongoing revenue trends without repeatedly writing aggregation queries, a permanent SQL view was constructed. It aggregates daily income while filtering out outlier records from year 2019:

```sql
CREATE VIEW net_revenue_per_month AS
SELECT
    "SaleDate" AS Date,
    SUM("income") AS Net_Revenue
FROM saleinfo
WHERE EXTRACT(YEAR FROM "SaleDate") <> 2019
GROUP BY "SaleDate"
ORDER BY "SaleDate";
```

## 3.2 VIP Client Profiling View and Excel Export
To support operational stakeholders including Public Relations and Client Relations teams, an integrated analytical view was deployed. It joins all three normalized tables to profile high volume buyers owning 10 or more properties:

```sql
CREATE VIEW our_most_importent_customers_17 AS
SELECT
    o."OwnerName" AS customer,
    o."ownercityaddress" AS customer_city,
    COUNT(o."OwnerName") AS propertyowned,
    MAX(p."LandUse") AS land_type_attract,
    MAX(p."propertyage") AS property_age_attract,
    ROUND(AVG(p."SquareMeters"), 2) AS avg_squaremeters,
    ROUND(AVG(s."SalePrice"), 0) AS avg_deal_price,
    ROUND(AVG(s."income"), 0) AS avg_revenue,
    SUM(s."income") AS all_net_revenue
FROM ownerinfo o
LEFT JOIN saleinfo s USING ("UniqueID")
LEFT JOIN propertyinfo p USING ("UniqueID")
WHERE s."income" IS NOT NULL
GROUP BY o."OwnerName",
         o."ownercityaddress"
HAVING COUNT(o."OwnerName") >= 10
ORDER BY "propertyowned" DESC;
```

## 4. Investigating the Revenue Mystery: Key Analytical Discoveries
Plotting net revenue revealed a compelling trend: transactions in 2013 and early 2014 produced negative net revenue, followed by a dramatic turnaround and massive profit expansion through 2015 and 2016.

[images/net_revenue_daily_plot.png]

[images/monthly_net_revenue_plot.png]

A thorough investigation was conducted to explain this shift:

## Discovery 1: Ruling Out Population Growth
A common assumption is that demographic influx drove the profit surge. Testing this hypothesis against official Nashville government demographic statistics revealed:

- Population in 2012: 649318 residents
- Population in 2017: 691243 residents
- Total 5 year increase: 41925 residents (an increase of approximately 6.5 percent)

Conclusion: A modest 6.5 percent population increase over five years cannot account for an exponential revenue jump from negative numbers to hundreds of millions. Population growth was definitively ruled out as the primary cause.

[images/nashville_population_trend.png]

## Discovery 2: The Drag of Vacant Land versus Built Property Profits
Segmenting transactions by occupancy status (SoldAsVacant) uncovered a fundamental structural insight:

- Vacant Properties (SoldAsVacant = Yes): Generated consistent losses, losing 31697758 across 440 transactions in 2013, and losing 54470575 across 831 transactions in 2014. In 2014, vacant property sales averaged an extreme loss of over 65000 per deal.
- Built Properties (SoldAsVacant = No): Experienced a rapid rebound, moving from a mild negative average loss in 2013 to generating 129767358 in positive net income in 2014, expanding to 310033309 in 2015, and reaching 563210202 in 2016.

Conclusion: Vacant property sales acted as a severe financial drain during 2013 and 2014, while developed properties served as the true growth engine of the portfolio.

[images/vacant_vs_built_revenue_comparison.png]

## Discovery 3: The Heavy Impact of Very Modern Properties
Examining net revenue by property construction age identified the single largest contributor to early losses:

- Very Modern Properties (Built after 2009): Suffered extreme losses in the early period, losing 97722797 in 2013 across 479 deals, and losing 95891021 in 2014 across 635 deals.
- Older Architectural Eras: Properties built in the Mid Century (1950 to 1969) and Old (1900 to 1949) eras remained resilient in 2013 and experienced massive profits in subsequent years, generating over 170 million each in 2016.
- Recovery: By 2016, modern property losses ceased completely as market demand caught up, turning positive to generate 43994699.

[images/property_age_sales_and_revenue_charts.png]

## Discovery 4: Capital Cost Reductions Expanding Profit Margins
Comparing the total assessed values (TotalValue) with net revenue showed that recorded capital cost baselines decreased in 2016:

- For Very Modern homes, total assessed valuation dropped from 325.5 million in 2015 to 184.7 million in 2016.
- For Mid Century homes, total valuation decreased from 498 million to 428.5 million.
- For Old homes, total valuation dropped from 418 million to 350.6 million.

Conclusion: Lower assessed baseline costs combined with record market sale prices widened the net margin significantly, driving peak profitability in 2016.

[images/total_value_vs_revenue_table.png]

## Discovery 5: Single Family Residences as the Core Customer Market
Evaluating land usage confirmed that single family homes represented the core foundation of transaction volume and financial returns:

- Sales Volume: Single family home transactions climbed from 7028 in 2013 to 9778 in 2015, and 8403 in 2016.
- Net Income Explosion: Single family properties generated 64.2 million in 2014, 266.1 million in 2015, and an unprecedented 487477085 in 2016 alone.
- Customer Persona: Commercial transactions (such as offices, shopping centers, and industrial facilities) were statistically negligible. The overwhelming majority of buyers were end user families seeking permanent single family housing.

## 5. Strategic Market Dynamics
## 5.1 Geographic Concentration
Mapping property counts across municipal boundaries revealed extreme spatial clustering:

- Nashville Proper: Accounts for 40209 properties, representing over 70 percent of all transactions.
- Surrounding Secondary Hubs: Antioch (6284), Hermitage (3126), Madison (2113), Brentwood (1696), and Old Hickory (1415).

[images/property_count_by_city_barchart.png]

## 5.2 Seasonality and Optimal Deal Timing
Year over year monthly analysis demonstrated clear seasonal cycles across all four years:

- Deal Prices: Average transaction prices consistently rise throughout spring and peak during mid year (May, June, and July), reaching 240000 in June 2016 before cooling during autumn and winter.
- Net Revenue: June 2016 achieved the highest monthly net revenue on record, generating nearly 100 million in a single month.
- Strategic Insight: This mid year peak mirrors the family relocation calendar, as households systematically purchase and move during the summer break to avoid disrupting the school year.

[images/seasonality_monthly_trends_chart.png]

## 5.3 Tax District Dynamics: Volume Scale versus Luxury Enclaves
Evaluating the impact of municipal tax districts highlighted the contrast between scale and luxury:

- Urban Services District (USD): Operates as the economic powerhouse of the region. Despite moderate average prices (around 195000), its immense volume of 4845 transactions per year drove virtually all net revenue expansion, generating 492 million in 2016 alone.
- Luxury Enclaves: Prestigious zones like the City of Belle Meade (average price 1.2 million) and the City of Forest Hills (average price 650000) recorded the highest individual property valuations, but their modest volume (57 and 97 deals per year) had an insignificant impact on total portfolio revenue.
- General Services District (GSD): Delivered steady, moderate performance with lower average prices (140000) and 1104 deals per year, producing stable returns of approximately 50 million in 2016.
